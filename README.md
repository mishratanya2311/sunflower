# 🌻 Sunflowers — Drawn Into Bloom

A beautiful animated sunflower artwork created using **HTML, CSS, JavaScript, and SVG**. This project brings a cluster of sunflowers to life through a gradual drawing and painting animation against a deep black background.

## ✨ Features

- 🌻 **Animated Sunflowers:** Multiple sunflowers appear gradually through a drawing sequence.
- 🎨 **SVG Artwork:** Detailed petals, flower centers, stems, and leaves created dynamically using SVG.
- 🌈 **Gradient Effects:** Custom gradients add depth and natural colors to petals, leaves, and stems.
- ✍️ **Drawing Animation:** SVG strokes animate along their paths, creating a hand-drawn effect.
- 🌿 **Botanical Details:** Layered petals, leaf veins, textured flower centers, and decorative highlights.
- 🌌 **Dark Background:** A subtle golden glow and grain texture create an elegant visual atmosphere.
- 📱 **Responsive Layout:** The artwork adjusts to different screen sizes.
- ⚡ **No External Libraries:** Built entirely with vanilla HTML, CSS, JavaScript, and SVG.

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling, gradients, transitions, and keyframe animations
- **JavaScript** — Dynamic SVG generation and animation timing
- **SVG** — Scalable vector artwork, shapes, paths, and filters

## 🚀 How to Run

1. Download or copy the project code.
2. Create a folder named `sunflowers`.
3. Save the HTML code as `index.html`.
4. Open the file in your browser.

Alternatively, open the folder in Visual Studio Code and run `index.html` using the **Live Server** extension.

No package installation or build process is required.

## ⚙️ How It Works

### 1. Dynamic SVG Generation
JavaScript creates flower petals, leaves, stems, and flower centers as SVG elements.

### 2. Drawing Animation
SVG paths use `stroke-dasharray` and `stroke-dashoffset` to animate the drawing of outlines and veins.

### 3. Sequential Painting
A timed animation sequence gradually reveals the artwork, adding color and detail to each flower.

### 4. Gradients and Texture
SVG gradients and filters add dimensional color, soft background lighting, and a subtle grain effect.

### 5. Multiple Flowers
Each sunflower has its own position, size, petal count, and animation timing to create a layered composition.
